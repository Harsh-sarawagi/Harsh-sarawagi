## Design research and credits

These open-source portfolios informed the design direction. This portfolio is an original implementation; their source code and assets were not copied.

- [Brittany Chiang v4](https://github.com/bchiang7/v4): readable project hierarchy and concise experience storytelling.
- [Bruno Simon folio-2019](https://github.com/brunosimon/folio-2019): 3D as an interactive personal signature.
- [Simplefolio](https://github.com/cobiwave/simplefolio): focused visitor journey from introduction to work to contact.
