SOFTWARE DEVELOPER INTERN

Making monitoring
more intelligent.

At BNY, I worked on making application monitoring easier to access and act on. I designed and developed a unified Health Check Agent using Python and FastAPI, exposing 19+ MCP tools through JSON-RPC 2.0, MCP clients, and Swagger UI.

  • Connected operational systems. Integrated Oracle DB, Splunk, and App Engine to centralize application health, logs, and operational information across production and QA environments.
  • Made monitoring proactive. Built parallel hourly health checks to detect anomalies and trigger severity-based email alerts.
  • Brought AI into the workflow. Added a RAG tool for application documentation and connected monitoring tools to BNY’s internal AI platform using Nuggets, enabling natural-language requests and tool selection.

Beyond the implementation

The internship helped me connect the stages of the software development lifecycle (SDLC): understanding a requirement, implementing a solution, integrating it with existing systems, and validating its behavior.

I also developed a better understanding of professional work culture—communicating progress, asking focused questions, responding to feedback, and taking responsibility for how my work fits into a larger team.
